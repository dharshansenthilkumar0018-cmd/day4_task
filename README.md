# Day 4 — Open LLM Memory, Quantization and Licence Analysis

This repository contains the Day 4 task submission.

## Files

- `vram_estimate.py` — memory estimator plus context/quantization experiments.
- `analysis.md` — full written analysis and required tables.
- `screenshots/` — evidence screenshots from the lab.

## Run

```powershell
python vram_estimate.py
```

The estimator uses the Day 4 lab concepts: weights, KV cache, runtime overhead, context length and quantization.

## Scenario

Local open-model assistant/coding helper on a laptop with a 16 GB memory budget.
